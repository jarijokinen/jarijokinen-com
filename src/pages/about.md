I'm Jari Jokinen, a software engineer from Helsinki, Finland.

I've been developing software for more than 25 years, working across web and
mobile apps, cloud platforms, Linux servers, embedded systems and algorithmic
trading. My experience also includes web application and server security,
penetration testing and security hardening.

I've worked as a freelance developer since 2007, providing software development
and consulting services to businesses.

## What I work with

### Web & backend

I build web applications, APIs and backend services, from small standalone
systems to larger distributed applications. My current work is primarily based
on TypeScript/JavaScript and Node.js, with extensive experience in databases,
system integrations and frontend development.

### Mobile

I develop cross-platform and native mobile applications for Android and iOS,
including integration with backend services, native platform APIs and
third-party SDKs. My work covers the full application lifecycle, from
architecture and development to testing, deployment and maintenance.

My current mobile work is primarily based on React Native and TypeScript,
with experience in native Android and iOS development when platform-specific
code is needed.

### Infrastructure

I design, build and operate the infrastructure that applications run on, with
a focus on Linux and AWS. My work includes cloud architecture, infrastructure
as code, containerization, CI/CD, networking, monitoring, security and
production troubleshooting.

I use tools and services including AWS, Linux, Terraform, Docker, Kubernetes
and GitHub Actions, and prefer infrastructure that is simple, reproducible and
easy to operate.
